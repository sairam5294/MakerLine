| # | File · section | Issue | Type | Effect / suggestion |

| 1 | `product-standards/references/context-budget.md` · Token rule 4 "Copy templates, don't read them" vs `design-direction/SKILL.md` step 10 "read only its HOW TO FILL comment and one example screen" | The wireframe template cannot be filled by `cp` + targeted edits without knowing its CSS class kit and the `<script>` block's expectations (`.screen`, `data-title`, `h2`, `#index`).
