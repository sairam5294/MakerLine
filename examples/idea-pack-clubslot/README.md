# Example Idea Pack — "ClubSlot" (blind eval run, 16 Oct 2026)

Produced by an agent following the kit's skills blind (it never saw the answer key) from the brief in `evals/cases/community-amenities`. The owner was treated as unavailable, so decisions are defaults marked for confirmation.

Start with [`docs/product/ONE_PAGER.md`](docs/product/ONE_PAGER.md), then [`docs/product/README.md`](docs/product/README.md) for the index. Wireframes: open `design/wireframes/index.html` in a browser (add `?mode=prototype` to click through).

What it shows: a brief claiming "no competitors" gets a researched Pivot verdict (MyGate, NoBrokerHood, ADDA, ApnaComplex), the strongest version worth testing (fair booking for contested amenities), a path to Go, design direction, wireframes and a draft PRD for the pivot.

Prices, ratings and review quotes were checked on the dates shown in the files and will go stale.

## What the kit got wrong on this run
The agent logged 29 friction points (fixed in 0.7.0): no owner-unavailable mode, Drop/Pivot rules overlapped, no rule on whether to design the brief or the pivot, US App Store ratings for an India product, non-button option chips in the wireframe template. See `LESSONS.md`.
