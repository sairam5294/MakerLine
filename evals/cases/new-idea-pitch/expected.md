# Must (1 point each)
1. Restates the idea in one line and asks to confirm
2. Does NOT re-ask what the pitch already answers (platform = Android first, location = Hyderabad, users = home bakers, monetization idea = subscription, owner designs) — confirms instead
3. Asks 3–5 questions per round, grouped by theme, in the skill's order
4. Multiple-choice questions with a recommended option first and short trade-offs
5. Probes the who/first-100 users (how many bakers the owner can reach, where they gather)
6. Probes the payer and willingness to pay (bakers' revenue, what they pay for today) — challenges nothing yet (no critique phase)
7. Asks about success metric / project goal (side income vs business vs learning)
8. Asks about end-customer side (do customers need an app/web link? likely a web order page)
9. Offers a provisional technology suggestion with a reason (e.g. Expo Android + web order link, Supabase, UPI/Razorpay) rather than only asking
10. Captures owner's unfair advantage (design skills; any baker contacts?)
11. Marks optional questions with a labelled default
Pass bar ≥ 9/11.
