<div class="section-intro">
<p class="eyebrow">How it works</p>
<h2 id="how">One line from idea to launch, with you in charge</h2>
<p>Every stop is a skill you can run on its own or all at once. The line stops before any code until you approve the idea, and no AI tool can approve it for you.</p>
</div>
<div class="line" data-reveal>
<p class="span idea" aria-hidden="true">MakerLine Idea · no code</p>
<p class="span all" aria-hidden="true">MakerLine · idea to launch</p>
<ol class="track">
<li><h3>Describe the idea</h3><p>A short interview, or just your pitch.</p><p class="files">PROJECT_BRIEF.md · CLARITY.md</p></li>
<li><h3>Get an honest evaluation</h3><p>A verdict, real competitors, the strongest version and who it leaves out.</p><p class="files">EVALUATION.md · COMPETITORS.md</p></li>
<li><h3>See it</h3><p>Design direction, clickable wireframes and a draft PRD.</p><p class="files">wireframes · PRD.md</p></li>
<li class="gate"><h3>You approve</h3><p>Nothing is built until you say so.</p><p class="files">Only you can sign this off</p></li>

<li><h3>Build, review, ship</h3><p>One task at a time, tests first, reviewed for accessibility and security.</p><p class="files">PLAN.md · RELEASE.md</p></li>

<section aria-labelledby="compare" markdown="1">
<p class="eyebrow" markdown="0">Why a plugin</p>
<h2 id="compare">Why not just ask Claude?</h2>

You can. MakerLine is everything you'd have to remember to ask for, every time, in every tool.

| | Asking in a plain chat | A PRD or spec template | MakerLine |
|---|---|---|---|
| Finds real competitors, with sources | If you ask | No | Every run |
| Tells you to pivot or stop | Rarely; chats tend to agree with you | No | A verdict with a confidence level |
| Accessibility law where you launch | If you know to ask | No | Every evaluation |
| Writes down what it doesn't know | No | Partly | Every unknown, in `CLARITY.md` |
| Stops before code until you approve | No | No | Enforced by hooks and CI |
| Checks its own work | No | No | A checker, tests and axe |
| Keeps your rules next session | No | No | In your repo, for 15 AI tools |
| Where your work lives | A chat thread | One document | Plain files in your folder |

</section>

<section aria-labelledby="try" markdown="0">
<p class="eyebrow">Try it</p>
<h2 id="try">Type one sentence to start</h2>
<p>Connect an empty folder to a new Claude chat, then type one of these.</p>
<ul class="prompts">
<li><code>/makerline:start give me everything for this idea, quick: a booking app for small physio clinics</code></li>
<li><code>Who are my competitors, and is my differentiator real?</code></li>
<li><code>What would it look like? Show me wireframes.</code></li>
<li><code>Make my tool plan. I have Claude, ChatGPT and Cursor.</code></li>
</ul>
<p>Using the MakerLine Idea plugin? Type <code>/makerline-idea:start</code> instead.</p>
</section>

<section id="install" aria-labelledby="install-h" markdown="0">
<p class="eyebrow">Install</p>
<h2 id="install-h">Two minutes to install</h2>
<div class="two">
<div class="panel">
<h3>Claude app, desktop or web</h3>
<ol>
<li>Open <strong>Customize</strong>, then <strong>Plugins</strong>.</li>
<li>Choose <strong>Add marketplace</strong> and enter <code>sairam5294/makerline</code>.</li>
<li>Install <strong>makerline</strong> or <strong>makerline-idea</strong>, not both.</li>
<li>Turn on <strong>Sync automatically</strong> to get updates.</li>
</ol>
</div>
<div class="panel">
<h3>Claude Code</h3>
<pre tabindex="0"><code>claude plugin marketplace add sairam5294/makerline
claude plugin install makerline@makerline</code></pre>
<p>Check it worked: type <code>/makerline:</code> in a new chat and the skills appear.</p>
</div>
</div>
</section>

<section aria-labelledby="which" markdown="1">
<p class="eyebrow" markdown="0">Compare</p>
<h2 id="which">MakerLine or MakerLine Idea?</h2>

| | MakerLine Idea | MakerLine |
|---|---|---|
| Best for | Deciding whether an idea is worth building | Building and shipping it once you've decided |
| You get | An Idea Pack: brief, evaluation, competitors, wireframes, draft PRD, one-pager, validation tests | Everything in MakerLine Idea, plus brand, stack, design system, engineering docs, repo setup, build, review, test and ship |
| Writes code | No | Yes, after you approve |
| Needs a terminal | No | Only for building |
| Start with | `/makerline-idea:start` | `/makerline:start` |

Not sure? Start with MakerLine Idea. If you decide to build, switch to MakerLine: your documents stay in your folder and `/makerline:start` picks up where you left off.

</section>
