# New Idea — Discovery

Goal: understand the idea well enough to evaluate it honestly, and make every unknown visible instead of guessed.

1. Get the pitch (2–5 sentences); restate it in one line; confirm. First reply ≤ 150 words + round-1 questions. Set expectations in one sentence: "Next I'll interview you, then give an honest evaluation with competitors, a strengthening plan, a design direction and a draft PRD."
2. Read `docs/product/OWNER.md` (skills, hours, budget, accounts, preferences) and pre-fill from it and the pitch — never re-ask, only confirm. Ask for missing OWNER.md fields once and offer to save them to the kit's `owner/OWNER.md`.
3. Interview in 4–6 rounds of 3–5 questions from `references/question-bank.md`, order: problem/goal → users → alternatives & differentiator → scope/platforms → design → technology → business → naming. Multiple choice (AskUserQuestion if available). **Decisions** (goal, platform, scope, stack) get a recommended first option with a one-line trade-off; **facts** about users/market (what they use today, what happened) never do — a "recommended" fact is a leading question. Core questions required; optional ones get a labelled default.
4. Ask who the owner thinks they're up against and why someone would switch — record it as a **hypothesis** (evaluate-idea researches the real landscape; don't argue now).
5. Offer technology suggestions, not just questions: give a provisional recommendation based on answers so far (final choice happens in tech-stack).
6. Make vague answers testable ("everyone" → "who are your first 100 users and where are they?").
7. Capture the owner's unfair advantages.
8. Write `docs/product/PROJECT_BRIEF.md` from `references/brief-template.md`; label assumptions. Write `docs/product/CLARITY.md` from `references/clarity-template.md`: every open question with the phase it blocks, its type (decision / fact / assumption), how to find out, and a default only for decisions. Rank the assumptions the idea depends on.
9. Show a 6–8 line summary + the readiness line ("Evaluation can start; 3 questions block approval"), get confirmation, set STATUS Discovery: Done, offer evaluate-idea.

No critique in this phase — that's evaluate-idea. Every later skill reads CLARITY.md first and moves answered questions to "Answered" with the source.
