# Competitors — Lite (Quick mode)

Everything Quick needs; the full method is `competitive-analysis.md` (Standard and Deep). Cap: 600 words.

## Steps
1. **Landscape:** top 3 direct competitors + "doing nothing". One line each for indirect and substitutes, if any.
2. **One sourced complaint per competitor** (app-store reviews for the launch market, Reddit, G2). Store page won't load → one attempt, then "Unknown" + a CLARITY question.
3. **Differentiator test** — for each claimed differentiator answer all five:
   1. Do users care? (evidence) 2. Noticeably better in the first session? 3. Can the leader copy it in a quarter? 4. Can this owner deliver it? 5. One sentence?
   Keep those passing 1, 2, 4, 5; for a fail on 3, name what makes it stick (community, data, distribution, local knowledge, trust, focus).
4. **Wedge and positioning statement.**
