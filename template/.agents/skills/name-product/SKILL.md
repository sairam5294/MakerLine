# Name Product

1. Read brief (audience, languages, feel, naming prefs) + evaluation positioning. Confirm criteria only if missing.
2. Generate 12–15 names: descriptive, evocative, invented/compound, culture/language-rooted (give script + accurate meaning). Skip excluded styles.
3. Score 1–5: memorable, easy to say/spell for the audience, meaning fit, distinctive, ≤ 12 chars for icon label, no negative meaning in target languages.
4. For the top 6, web-search App Store/Play name clashes, domain signals (.com/.in/.app), same-category companies/trademarks (IP India, USPTO, WIPO if reachable). Report what was checked vs not; never claim "available" — tell owner to confirm with a registrar/trademark professional.
5. Table (name · style · meaning · scores · conflicts · risk) + top 3 with a ≤ 6-word tagline each.
6. Save `docs/product/NAMING.md`; update brief + STATUS.

Avoid crowded dictionary words, near-clones of big brands, and disrespectful use of religious/cultural terms.
