# Competitors — Lite (Quick mode)

Everything Quick needs; the full method is `competitive-analysis.md` (Standard and Deep). Cap: 450 words. Real, named products with links and the date checked; never invent a competitor, number or review. Say plainly what incumbents do well.

**Differentiator test** — for each claimed differentiator: 1. Do users care? (evidence) 2. Noticeably better in the first session? 3. Can the leader copy it in a quarter? 4. Can this owner deliver it? 5. One sentence? Keep those passing 1, 2, 4, 5; for a fail on 3, name what makes it stick (community, data, distribution, local knowledge, trust, focus). A store page that won't load → one attempt, then "Unknown" + a CLARITY question.
