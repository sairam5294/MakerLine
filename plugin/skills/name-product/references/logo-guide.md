# Making the logo — the easy path

For a solo designer-founder: a clean, ownable mark in an afternoon, using free tools, that works from favicon to app icon.

1. **Start from the name, not a picture.** Most early products are best served by a wordmark (the name, well set) or a lettermark (one or two letters). A symbol only earns its place if it says something the name doesn't.
2. **Pick one typeface** from the brand's font pairing (open licence), try 3 weights, and adjust spacing by hand — letter-spacing and one custom detail (a cut, a ligature, a dot) make it yours.
3. **Build in Figma on a grid** (8 or 16 units). Convert text to outlines for the final file. Keep a source frame with the live text for edits.
4. **Test small first:** 16 px favicon and 24 px in a browser tab. If it doesn't read there, simplify (the mark-only version is for small sizes).
5. **Colour last:** one-colour version must work; then apply the brand primary; check the reversed version on the darkest background.
6. **Export:** SVG (logo, mono, reversed, mark), PNG favicon set and app icon 1024 (no transparency for iOS app icons), social preview 1200×630. Put everything in `design/brand/` with clear names.
7. **Check originality:** reverse-image search the mark and search the name + "logo" in the same category; avoid close resemblance to existing marks.
8. **AI image tools** are fine for mood boards and exploring directions, not for the final mark: the output can resemble existing marks, licensing varies, and you can't edit it precisely. Redraw any direction you like as vectors yourself.
9. **When to hire:** if the product gets traction and needs a full identity system, brief a designer with BRAND.md — it already holds the positioning, palette, type and rules.
