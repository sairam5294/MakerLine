# Product Kit (Claude plugin) v0.5

This plugin takes an idea from first conversation to launch, with approval gates. Start by saying **"I have a new idea"** or running `/product-kit:product-kickoff`.

**Skills**
- **Workflow:** product-kickoff, new-idea, evaluate-idea, validate-idea, name-product, tech-stack, design-system, write-prd, plan-build, build-feature, design-qa, quality-review, test-plan, ship-checklist, post-launch, ai-feature
- **Anytime:** handoff, portfolio, standards-refresh
- **Rulebook:** product-standards

**Agents:** market-researcher, devils-advocate, product-strategist, architect, ux-reviewer, accessibility-auditor, security-reviewer, code-reviewer, qa-engineer, web-developer, mobile-developer, backend-developer

Project templates, safety settings, CI and the Expo starter live in the full `product-kit` repo. Create a project with `scripts/new-project.sh`.
