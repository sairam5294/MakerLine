# Idea Pack — a Claude plugin

Turn a product idea into everything you need to decide whether to build it, before writing any code:

- **Discovery** — planned questions, a brief, and a clarity log of every open question and what it blocks
- **Honest, constructive evaluation** — the strongest version of the idea, a reality check, a scorecard with how to raise every weak score, and a path to Go
- **Competitors** — direct, indirect, substitutes and "doing nothing", with real review complaints and a five-question differentiator test
- **Accessibility, inclusion and compliance** — who the idea could exclude, and the law in each launch market (AODA, ADA, Section 508, the European Accessibility Act, UK, India and more). The baseline is accessible worldwide with no discrimination.
- **Design direction** — principles, flows, 2–3 contrast-checked visual directions and clickable grey-box wireframes
- **Draft PRD and a one-pager**

Three depths: **Quick**, **Standard** and **Deep**. A checker script verifies the pack before you see it.

This is the idea-stage part of [Product Kit](https://github.com/sairam5294/product-kit). Install the full kit when you decide to build: naming, tech stack, design system, build with an approval gate, reviews, testing and shipping.

## Install
- Claude Code: `claude plugin marketplace add sairam5294/product-kit`, then `claude plugin install idea-pack@product-kit-marketplace`
- Claude app: open `idea-pack.plugin` (from the kit's releases, or built with `scripts/build-idea-pack.py --zip`) and press Install.

## Use
Say "I have an idea…" or "give me everything for this idea: …". Add "quick" for a fast first look.
